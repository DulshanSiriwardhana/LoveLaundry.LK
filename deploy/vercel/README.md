# Vercel env templates

One `.env.example` per Vercel project. Copy the values into the matching Vercel project's **Environment Variables** (dashboard or `vercel env add`). Do not commit files containing real secrets.

See [`../../VERCEL_DEPLOYMENT.md`](../../VERCEL_DEPLOYMENT.md) for the project/Root Directory mapping and deployment order.

`00-shared.env.example` is a reference for values that must be identical across several services; it is not a project of its own.
